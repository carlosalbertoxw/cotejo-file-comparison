## Guardar respeta los permisos del archivo

Al guardar, el archivo conserva su propietario y sus permisos. Hasta ahora se sustituía por uno
nuevo con los permisos por defecto: en Linux y macOS, un script perdía el permiso de ejecución y un
archivo privado —de los que solo puede leer su dueño— quedaba legible para otros usuarios del
equipo. También dejaba de estar sincronizado con sus enlaces duros, que se quedaban con el
contenido de antes; ahora se escriben en su sitio, igual que los enlaces simbólicos.

## Dónde guarda sus archivos

«Acerca de» tiene una sección nueva, **Archivos del programa**, con las rutas en las que Cotejo
escribe en ese equipo:

- La carpeta de datos, donde se guardan las preferencias, las pestañas abiertas, el historial y la
  caché. Un botón la abre en el explorador de archivos.
- La carpeta temporal a la que se descomprime la versión sin instalar —el `.exe` portable o el
  AppImage—, solo cuando se usa una de ellas.
- El archivo temporal `.<número>.cotejo-tmp` que se escribe junto a cada archivo al guardar. Si
  alguna vez aparece uno suelto, es de un guardado que se cortó, y se puede borrar.

## La comprobación de versiones se puede apagar

«Acerca de» tiene una casilla para que Cotejo deje de preguntar a GitHub una vez al día si hay una
versión nueva. Es la única conexión que hace la aplicación; con la casilla desmarcada no sale nada
del equipo salvo cuando se pulsa **Buscar actualizaciones**.

## Ejecutable más cerrado

El ejecutable de Cotejo ya no se puede usar como intérprete de Node, no acepta código inyectado
por variables de entorno ni por opciones de depuración, y en Windows y macOS se niega a arrancar si
alguien ha modificado sus archivos internos. Tampoco concede ningún permiso del navegador
(cámara, micrófono, notificaciones…), que Cotejo nunca ha necesitado.

Además, Electron pasa a la 43.7.5, con las correcciones de seguridad de Chromium publicadas desde
la versión anterior.

## Descargas que se pueden comprobar

Cada release trae un `SHA256SUMS.txt` con la huella de cada archivo, y una atestación de GitHub
que certifica que los instalables salieron del workflow de release de este repositorio y de qué
commit. Los instalables siguen sin firmar, así que los avisos de Windows y macOS no cambian, pero
ya hay forma de comprobar que lo descargado es lo que se publicó. El README explica cómo.
